# Основа: демо-сайт строительной компании

Учебный проект для портфолио: лендинг на HTML/CSS/JS и бэкенд на FastAPI.
Компания, цены и контакты вымышлены.

## Что умеет

- Калькулятор стоимости: тип работ, площадь, уровень отделки. **Цену считает сервер**
  (`POST /api/calc`), в браузер не отдаются ни цены за метр, ни коэффициенты.
- Заявка (`POST /api/lead`) может содержать расчёт. Сумму сервер пересчитывает сам,
  поэтому подменить её со стороны браузера нельзя.
- Проверка данных, ограничение частоты (5 заявок в час с одного IP), ловушка для ботов.
- Закрытая страница `/admin` со списком заявок и расчётами (логин `admin`, пароль из `ADMIN_PASSWORD`).
- Защитные заголовки (CSP и другие), экранирование данных в админке.

## Структура

```
stroy-demo/
├── app/
│   ├── main.py        # маршруты, проверка данных, админка
│   ├── calc.py        # расчёт стоимости (чистые функции)
│   ├── rates.json     # ставки: меняете цены здесь
│   ├── db.py          # SQLite
│   └── ratelimit.py   # ограничение частоты
├── static/            # index.html, css/style.css, js/main.js
├── tests/             # test_calc.py, test_api.py
├── render.yaml        # настройка деплоя на Render
└── .env.example       # образец настроек, копируется в .env
```

## Запуск у себя

```bash
conda create -n stroy python=3.12
conda activate stroy
pip install -r requirements-dev.txt
copy .env.example .env        # macOS/Linux: cp
pytest
uvicorn app.main:app --reload
```

Сайт: http://127.0.0.1:8000, админка: http://127.0.0.1:8000/admin

## Как поменять цены

Откройте `app/rates.json`: `price_m2` это цена за м², `k` коэффициент уровня отделки,
`spread` ширина коридора (0.1 значит ±10%). После правки запустите `pytest`: тест
`test_estimate_known_value` рассчитан на текущие ставки, и его ожидаемое значение
нужно будет обновить.

## Деплой на Render

Тот же порядок, что для первого проекта: репозиторий на GitHub, на Render New → Blueprint,
выбрать репозиторий, ввести `ADMIN_PASSWORD`. Бесплатный тариф засыпает после простоя,
база SQLite на нём не сохраняется между перезапусками, свой домен не подключить.

## Важно про данные

В демо не вводите реальные имена и телефоны. Для боевого сайта с российскими клиентами
понадобятся политика конфиденциальности под конкретную компанию, хранение персональных
данных на серверах в РФ (152-ФЗ) и постоянная база.
